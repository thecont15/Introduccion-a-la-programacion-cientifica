El grafo propio

Doce estaciones, dieciséis tramos, cuatro líneas.

Qué es cada cosa

Vértice: una estación.

Arista: un tramo con servicio directo entre dos estaciones.

Peso: los minutos que dura ese tramo. Siempre positivo. El número escrito sobre la línea manda: el largo del trazo en pantalla no es el peso.

Cómo se cuenta un transbordo

Siguiendo el enunciado: cambiar de línea es seguir una arista. Cada tramo que se toma cuenta como un transbordo, así que minimizar transbordos es minimizar aristas, y esa es exactamente la pregunta que responde BFS.

Los minutos son otra cosa: una suma. Esa es la pregunta de Dijkstra.

La Red Valle Alto y sus estaciones son inventadas. No es un sistema real ni el mapa del ejemplo de clase.

Una red, dos preguntas

Contar tramos y sumar minutos no son el mismo problema.

BFS · menos transbordos

Avanza por olas con una cola: primero las vecinas del origen, después las vecinas de esas. Si cada tramo cuenta 1, la primera vez que una estación entra a la cola ya trae el mínimo de tramos, y por eso no se vuelve a encolar.

Responde un conteo. No sabe que un tramo dura 19 minutos y otro 3: los dos valen 1.

Dijkstra · menos minutos

Cada estación guarda su mejor marca en minutos y la estación previa con la que la consiguió. En cada paso se confirma la pendiente con menos minutos; como los pesos no restan, esa marca ya no puede bajar.

Responde una suma. Probar un tramo es marca(u) + minutos(u,v) contra la marca que ya tenía v.

La trampa de esta red

—

—

Para BFS ese tramo vale 1, igual que los de 3 o 4 minutos. Así que lo toma, y gana en conteo. Para Dijkstra es carísimo, y lo descarta.

Si todos los tramos duraran lo mismo, las dos preguntas tendrían la misma respuesta. Se separan justamente porque los minutos son distintos.

Lo que sigue son los dos laboratorios: primero la cola de BFS, después los pendientes de Dijkstra. Al final, las dos rutas una al lado de la otra.

      Del dibujo al código

      La cola y la cola de prioridad.

      La red es un diccionario de vecinas. Para BFS basta la lista de vecinas; para Dijkstra hace falta el par (vecina, minutos). Es el mismo mecanismo de los laboratorios, sin la animación.

      from collections import deque
import heapq

RED = {
    "Portal Norte": [("Aurora", 4), ("Mirador", 3)],
    "Aurora":       [("Bulevar", 19), ("Las Ferias", 6), ("Portal Norte", 4)],
    "Mirador":      [("La Cumbre", 8), ("Portal Norte", 3), ("El Tejar", 4)],
    # ... el resto de la lista de adyacencia
}

def menos_transbordos(red, origen, destino):
    """BFS: cuenta tramos. Cada tramo vale 1, duren lo que duren."""
    tramos = {origen: 0}
    previo = {origen: None}
    cola = deque([origen])
    while cola:
        u = cola.popleft()
        if u == destino:
            break
        for v, _minutos in red[u]:          # los minutos no se usan aqui
            if v not in tramos:
                tramos[v] = tramos[u] + 1
                previo[v] = u
                cola.append(v)
    return tramos.get(destino), previo

def menos_minutos(red, origen, destino):
    """Dijkstra: suma minutos positivos."""
    marca = {origen: 0}
    previo = {origen: None}
    confirmadas = set()
    pendientes = [(0, origen)]
    while pendientes:
        d, u = heapq.heappop(pendientes)
        if u in confirmadas:
            continue
        confirmadas.add(u)                  # su marca ya no puede bajar
        if u == destino:
            break
        for v, minutos in red[u]:
            nueva = d + minutos
            if nueva < marca.get(v, float("inf")):
                marca[v] = nueva
                previo[v] = u
                heapq.heappush(pendientes, (nueva, v))
    return marca.get(destino), previo

def reconstruir(previo, destino):
    ruta, c = [], destino
    while c is not None:
        ruta.append(c)
        c = previo[c]
    return ruta[::-1]

      deque.popleft() saca el frente de la cola: eso es la ola de BFS. heapq es la cola de prioridad: siempre entrega la estación pendiente con menos minutos acumulados. Cambiar una estructura por la otra es cambiar de pregunta.

      Porque trata cada tramo como 1. El Expreso de 19 minutos le gana a cinco tramos cortos, aunque la suma de esos cinco sea menor. BFS responde un conteo; los minutos son una suma.

      Las dos preguntas coincidirían: minimizar tramos sería minimizar minutos, y la ruta de BFS, multiplicada por 5, sería la de menos minutos. Las respuestas se separan solo porque los minutos difieren entre tramos.

      Depende de qué le cueste más. Si lo que pesa es el tiempo, la ruta del Cable. Si lo que pesa es bajarse y volverse a subir cinco veces con equipaje, el Expreso. El grafo no decide eso: decide cuál es el mínimo de cada medida.
